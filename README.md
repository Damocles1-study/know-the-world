# 认识世界 · 使用与扩展手册

一本本地电子书。**双击 `index.html` 就能读**，不需要网络、不需要服务器、不需要安装任何东西。

---

## 一、怎么读

| 操作 | 说明 |
|---|---|
| 双击 `index.html` | 打开。建议用 Chrome / Edge / Safari |
| `⌘K` 或 `/` | 全局搜索（词条名、英文名、一句话本质、关键词都能搜） |
| `←` `→` | 上一卷 / 下一卷 |
| 右上「随机」 | 从**你还没读过的**词条里随机跳一条。适合每天读一条 |
| 右上 `◐` | 明暗主题切换 |
| 滚动 | 自动记录已读，侧栏打勾，首页显示进度 |

阅读进度存在浏览器的 localStorage 里。**换浏览器或清缓存会清零**，内容本身不受影响。

**建议路线**：不必从头读。先读 **卷九 · 工具箱** 的「二十条总纲」和「停手清单」，做一遍「反诈自测」，看看哪几题错了，再回去读对应的卷。

## 二、文件结构

```
认识世界/
├── index.html            外壳（新增一卷时要加一行 <script>）
├── assets/
│   ├── style.css         视觉系统（颜色、排版、响应式）
│   ├── viz.js            可视化引擎（11 种图表）
│   └── app.js            路由、搜索、进度、工具箱交互
├── content/
│   ├── _manifest.js      卷册总表（卷名、副标题、颜色）
│   └── v1.js … v9.js     内容，一卷一个文件
└── README.md             本文件
```

**设计目的：外壳写一次，内容无限追加。**
改内容永远只动 `content/` 下的一个文件，不需要读 `app.js` / `style.css` / `viz.js`。

## 三、词条数据格式

一条词条就是一个对象。除 `id` `t` `one` 外全部可选。

```js
W.add('v4',                          // 卷 id
{
  id:'ponzi',                        // 唯一英文 id，用于锚点和交叉引用
  t:'庞氏骗局',                       // 标题
  en:'Ponzi Scheme',                 // 英文名（可选，灰色小字）
  tag:'scam',                        // idea概念 scam骗局 word话术 mind心智 life处世 rule规则 tool工具
  k:'资金盘 拆东墙补西墙',              // 额外搜索关键词（可选）
  one:'一句话本质，**可加粗**',         // 顶部那句大字，必填
  why:'为什么普通人吃亏',              // 可选段落
  an:'打个比方：……',                  // 类比，强烈建议写
  viz:{ /* 见下 */ },                 // 主图
  real:['现实例子一','现实例子二'],      // 列表
  viz2:{ /* 可选第二张图 */ },
  do:['怎么办一','怎么办二'],           // 绿色行动块
  see:['mlm','risk-premium']          // 相关词条 id，自动生成链接
});
```

文本里可用：`**加粗**`、`` `代码` ``、`<b>粗</b>`。其余 HTML 会被转义（防止排版被搞乱）。

## 四、可视化速查（11 种）

只写 JSON，图自动生成。颜色可省略，会自动配色；`var(--c1)`~`var(--c6)` 是内置六色，`var(--c2)`绿=好，`var(--c4)`红=坏。

```js
// 1 横向条形对比。第4个元素是右侧显示文字（可选）
{type:'bars', t:'标题', unit:'元', max:100,
 items:[['名称', 60, 'var(--c2)', ' 60 元'], ['另一个', 25]], note:'图注'}

// 2 一条被切开的百分比
{type:'stack', t:'', unit:'元', parts:[['成本',18],['渠道',35],['利润',10]]}

// 3 大数字
{type:'stat', items:[['18.25%','真实年化','var(--c4)'], ['0.05%','宣传日息']]}

// 4 两栏对照
{type:'split', t:'', lc:'var(--c4)', rc:'var(--c2)',
 left:{t:'骗局的样子', items:['…','…']}, right:{t:'正规的样子', items:['…']}}

// 5 资金/流程链（自动换行）
{type:'flow', t:'', ec:'var(--c4)',
 nodes:[['你','付钱'],['平台','截留'],['结果','']], edges:['转账','抽成']}

// 6 金字塔（从顶到底）
{type:'pyramid', layers:[['第1层 · 1人','赚'],['第5层 · 1296人','亏光']]}

// 7 时间线 / 剧本
{type:'steps', t:'', c:'var(--c4)', items:[['① 接近','说明'],['② 建立信任','说明']]}

// 8 四象限（顺序：左上 右上 左下 右下）
{type:'quad', x:['左轴','右轴'], y:['上轴','下轴'],
 items:[['标题','说明'],['','' ],['',''],['','']]}

// 9 冰山（表面 vs 水下）
{type:'ice', at:'你看到的', bt:'实际是', above:['…'], below:['…']}

// 10 折线（多条曲线，自动坐标轴，末端自动标注）
{type:'curve', t:'', x:['第1年','第2年'], unit:'万', zero:true,
 series:[{n:'年化3%', c:'var(--c1)', p:[10,11.6]}, {n:'年化8%', p:[10,14.7]}]}

// 11 小表格（最适合"他说 / 实际意思"这类对照）
{type:'table', t:'', head:['他说','实际意思'], rows:[['最高可达20%','通常到不了']]}
```

`t`（图标题）和 `note`（图注，支持 `**加粗**`）任何图都能加。

## 五、怎么低成本地继续扩充

这是这本书的**省 token 机制**：内容模块化 + 声明式图表，让每次续写只需要极少上下文。

### 情况 A：在已有卷里加几条

新开一个窗口，说：

> 读 `/Users/zyx/Downloads/认识世界/README.md`，然后在 `content/v4.js` 末尾追加 5 条词条：XXX、XXX、XXX。
> 严格照现有格式和文风（一句话本质 + 打比方 + 图 + 现实例子 + 怎么办），每条配一张图。**不要读其他文件。**

它只需要加载 README（约 2000 字）+ 目标文件，成本很低。

### 情况 B：新增一整卷

> 读 README，新建 `content/v10.js`，主题是「XXX」，写 12 条。
> 同时：在 `content/_manifest.js` 加一行 `W.vol({id:'v10', n:'十', t:'卷名', s:'侧栏副标题', c:'var(--c5)', d:'卷首介绍'});`
> 在 `index.html` 的脚本列表里加一行 `<script src="content/v10.js"></script>`。

### 情况 C：只想改几个字

直接自己用文本编辑器打开对应的 `content/vN.js` 改就行，都是纯文本。

### 省 token 的几条经验

- **一次说清一整卷**，比来回追问十次便宜得多。
- 明确说「不要读其他文件」「不要重构外壳」。
- 让它**一次性写完整个文件**（Write），不要一条条 Edit。
- 图表交给 `viz.js`，**不要让它手写 SVG**——那是最烧 token 的事。
- 不需要预览验证时就说「不用起服务器验证」。

### 如果要预览验证（可选）

`~/Downloads` 是 macOS 隐私保护目录，本地服务器进程可能读不到。最省事的办法是**直接双击 `index.html`**，一样能看全部效果。

## 六、内容边界（写新内容时请保持）

- **不提供投资建议。**只解释机制、只给可验证的事实和可执行的自保动作。
- 案例只用**公开报道过的**，用于说明结构，不指认个人。
- 涉及法律、利率、政策的数字，标注「以官方最新为准」，不要写死。
- 语气：**讲人话、给比喻、给具体动作。**不说教，不制造恐慌，也不假装世界很安全。
